Manual de Instalação e Configuração do Koha

Guia estruturado com foco em estabilidade operacional e automação segura via script.

Instalação Automatizada

Para instalar o sistema de forma limpa no servidor executando o script hospedado no repositório, utilize o comando abaixo:

Terminal Linux (Root) 
wget -O instalar.sh https://raw.githubusercontent.com/paulofbaldifh/Koha-/main/instalar.sh && sudo bash instalar.sh
