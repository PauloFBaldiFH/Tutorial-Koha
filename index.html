Manual Completo de Instalação e Configuração do Koha

Guia estruturado com foco em estabilidade operacional: preparação minuciosa do sistema operacional em 5 cenários, script automatizado com Elasticsearch, primeiro acesso web, restauração de banco de dados e publicação via Cloudflare Tunnel.

1. O que é e como funciona o Koha

O Koha é o sistema integrado de gestão de bibliotecas (ILS) de código aberto mais utilizado no mundo. Ele opera sobre a stack LAMP (Linux, Apache, MariaDB e Perl), funcionando como um servidor central corporativo.

Acesso Universal por Navegador

O sistema fica hospedado em uma única máquina servidora. Funcionários and leitores utilizam o Koha diretamente pelo navegador web (Google Chrome, Firefox, Edge), sem necessidade de instalar programas nos computadores de atendimento ou consulta.

O Koha opera obrigatoriamente através de duas portas de rede padronizadas:

  • Porta 8080 (Staff / Interface Administrativa): Painel restrito dos bibliotecários e atendentes. Utilizada para catalogação bibliográfica no padrão MARC21, controle de circulação (empréstimos e devoluções), cadastro de usuários, gestão de multas e geração de relatórios SQL.
  • Porta 80 (OPAC / Catálogo Público): Página pública voltada aos leitores. Permite consultar o acervo da biblioteca, checar disponibilidade nas estantes, renovar prazos e reservar títulos pela internet.

Gestão de Redes de Bibliotecas: Uma única instalação permite administrar múltiplas unidades físicas (como uma biblioteca central e várias filiais de bairros ou salas de leitura escolares). Todas compartilham o mesmo catálogo, mantendo o controle de estoque e regras de circulação individualizados.

2. Escolhendo a Hospedagem e Preparando o Sistema Operacional

O Koha foi concebido nativamente para rodar sobre Linux (Debian ou Ubuntu). A forma como você chega à linha de comando depende exclusivamente do método de instalação escolhido abaixo. Siga rigorosamente apenas o cenário que você escolheu:

Cenário 1: Servidor Físico Dedicado (Ubuntu Server)

Instalação limpa em um computador físico da biblioteca sem sistema operacional prévio.

  • Baixe a imagem oficial do Ubuntu Server LTS.
  • Crie um pendrive bootável utilizando o BalenaEtcher.
  • Acesse a BIOS da placa-mãe: desative o Secure Boot e o Fast Boot, configure o SATA Mode em AHCI e mude o AC Back para Power On.
  • Durante a instalação, selecione o disco inteiro e marque obrigatoriamente com a barra de espaço a opção "Install OpenSSH server".
  • Identifique o IP com o comando ip a e gerencie a máquina via SSH.

Cenário 2: Servidor em Nuvem / VPS

Instalação em um provedor de nuvem (DigitalOcean, Hetzner, AWS, Hostinger, etc.).

  • Crie uma instância com Ubuntu Server (22.04 ou 24.04 LTS).
  • Plano de Hardware Obrigatório: No mínimo 4GB de RAM e 2 vCPUs (planos menores travam na indexação do Elasticsearch).
  • Acesse remotamente via terminal SSH utilizando o IP público fornecido.

Cenário 3: Computador com Linux Gráfico (Linux Mint ou Ubuntu Desktop)

Instalação em uma máquina com área de trabalho visual.

  • Baixe a ISO do Linux Mint (Cinnamon) ou Ubuntu Desktop e grave no pendrive.
  • Instale o sistema de forma totalmente gráfica em português.
  • Vantagem Operacional: Não é preciso usar SSH! Abra o terminal nativo com Ctrl + Alt + T e execute os comandos diretamente.

Cenário 4: Windows usando VirtualBox

Execução do Ubuntu Server dentro de uma máquina virtual no Windows.

  • Ative a virtualização (Intel VT-x ou AMD SVM) na BIOS do Windows.
  • Instale o VirtualBox e baixe a ISO do Ubuntu Server.
  • Atenção Crítica: Na criação da VM, marque para Pular Instalação Desatendida (Skip Unattended Installation) para não perder o acesso ao OpenSSH.
  • Configure o hardware com pelo menos 4GB de RAM e 2 CPUs.
  • Na rede da VM, mude de NAT para Placa em modo Bridge (Bridged Adapter) apontando para sua placa de rede física, permitindo que a rede local acesse o Koha.

Cenário 5: Windows usando WSL2

A forma mais leve de rodar o kernel Linux integrado diretamente no Windows 10 ou 11.

  • Ative os recursos de virtualização e o subsistema Linux no painel do Windows.
  • Abra o PowerShell como Administrador e execute: wsl --install -d Ubuntu.
  • Crie seu usuário e senha do Linux. Fixe o atalho do Ubuntu na barra de tarefas.
  • Vantagem Operacional: Sem necessidade de SSH; basta abrir o terminal do WSL2 e rodar os comandos.

3. Identificação de IP e Acesso ao Terminal

Regra Clara de Acesso:

  • Cenários 3 e 5 (Linux Gráfico / WSL2): Você trabalha diretamente na máquina. Não precisa de SSH. Abra o terminal local.
  • Cenários 1, 2 e 4 (Servidor Físico / VPS / VirtualBox): O servidor roda em modo texto ou segundo plano. Você precisa conectar nele via PowerShell de outro computador usando SSH.

Como identificar o IP do Servidor

No terminal do Linux, execute:

Terminal Linux
ip a

Conexão Remota via PowerShell (Cenários 1, 2 e 4)

Para garantir que o redirecionamento de portas do Google Drive funcione perfeitamente durante a instalação, conecte-se via SSH com o seguinte comando no seu computador Windows:

PowerShell (Windows)
ssh -L 53682:127.0.0.1:53682 nomedousuario@ipdoservidor

4. Instalação Automatizada do Sistema

Com o terminal aberto e com privilégios de administrador (sudo -i), execute o comando abaixo para disparar o script de automação hospedado no repositório oficial:

Terminal Linux (Root)
bash <(curl -s https://raw.githubusercontent.com/PauloFBaldiFH/Koha-/refs/heads/main/instalar.sh)
O que o script executa: Sincronização NTP, criação de SWAP preventivo de 4GB, repositórios oficiais do Koha e Elasticsearch 7.x, instalação do MariaDB, Apache configurado nas portas 80 e 8080, configuração de backup diário com Rclone, autorização do Google Drive e pausa inteligente aguardando o término do Web Installer.

5. Concluindo o Web Installer no Navegador

Deixe a janela do terminal aberta. No seu navegador web, acesse o painel de instalação:

  • Cenários 1, 2 e 4: http://ipdoservidor:8080
  • Cenários 3 e 5: http://localhost:8080

Siga os passos do assistente:

  1. Etapa 1: Digite o usuário koha_library e cole a senha provisória gerada no terminal.
  2. Etapa 2: Selecione o idioma Português do Brasil (pt-BR).
  3. Etapa 3: Verifique os módulos Perl e selecione o formato MARC21.
  4. Etapa 4: Mantenha os frameworks do MARC21, mas desmarque todas as caixas de dados de exemplo (amostras de usuários/itens) para evitar registros fictícios.
  5. Etapa 5 e 6: Cadastre a sigla da biblioteca (ex: BPM) e a categoria administrativa STAFF.
  6. Etapa 7: Crie sua conta de Administrador (Superlibrarian) com uma senha forte e anote-a.
  7. Etapa 8 e 9: Defina o tipo de exemplar inicial (ex: LIV) e as regras básicas de circulação (dias de empréstimo e renovações).

Assim que você concluir o assistente no navegador, retorne ao terminal: o script detectará automaticamente a criação do usuário, injetará as regras do Elasticsearch, reindexará o acervo e finalizará o processo.

6. Restauração de Backup Anterior (Opcional)

Se você possui um dump SQL de uma instalação anterior (renomeado para koha_library.sql), coloque-o na sua pasta de usuário e execute o script automatizado de restauração e reindexação:

Terminal Linux (Root)
bash <(curl -s https://raw.githubusercontent.com/PauloFBaldiFH/Koha-Restore/refs/heads/main/restaurar.sh)

7. Publicando o Koha na Internet (Cloudflare Tunnel)

O Cloudflare Tunnel é a forma mais segura de expor o Koha sem abrir portas no roteador, entregando HTTPS automático e proteção avançada.

Passo 1: Domínio e Configuração na Cloudflare

Utilize um domínio próprio ou crie um subdomínio gratuito no DigitalPlat apontando para os nameservers da Cloudflare.

Passo 2: Criando o Túnel

No painel da Cloudflare (Zero Trust > Networks > Tunnels), crie um novo túnel, selecione Debian 64-bit e execute os dois comandos fornecidos no terminal do seu servidor.

Passo 3: Mapeamento de Rotas (Public Hostnames)

  • Staff (Administração): Subdomínio adm + Seu Domínio -> Serviço HTTP em localhost:8080
  • OPAC (Catálogo Público): Domínio raiz (sem subdomínio) + Seu Domínio -> Serviço HTTP em localhost:80

Passo 4 e 5: Proteção contra Bots e Ajustes no Koha

Ative o Bot Fight Mode na Cloudflare para bloquear scrapers de IA. Em seguida, acesse o painel Staff do Koha em Administração do Koha > Preferências do Sistema e ajuste os parâmetros OpacBaseUrl e StaffBaseUrl com as respectivas URLs públicas em HTTPS.
