Manual de Instalação e Operação do Koha

Guia definitivo para implantação automatizada do Koha ILS com Elasticsearch em ambientes Ubuntu Server.

Sobre o Projeto

Este manual documenta o processo de implantação de uma biblioteca digital utilizando o Koha integrado ao mecanismo de busca Elasticsearch. O objetivo é fornecer uma solução limpa, robusta e automatizada, garantindo alta performance nas buscas do acervo e segurança nos dados.

O que o Script Automatizado Realiza?

Para evitar erros manuais de digitação e inconsistências de pacotes, todo o processo técnico foi encapsulado em um script de automação inteligente. Ele executa as seguintes etapas:

  • Preparação do Sistema: Sincronização de relógio via NTP, fuso horário e criação de SWAP preventivo de 4GB.
  • Repositórios Oficiais: Adição segura das chaves GPG e repositórios oficiais do Koha (oldstable) e Elasticsearch 7.x.
  • Stack de Serviços: Instalação do MariaDB, Apache2 configurado para portas separadas (Staff 8080 e OPAC 80), Memcached e o plugin ICU para o Elasticsearch.
  • Instância e Configuração Web: Criação limpa da base de dados, pausa de daemons legados e espera inteligente até que o usuário conclua o assistente de instalação web (Web Installer).
  • Pós-Instalação Automática: Injeção segura das regras do Elasticsearch no XML, reindexação completa do acervo e ativação do commit imediato.
  • Rotina de Backup: Configuração de script de dump diário compactado integrado ao Rclone para envio automático ao Google Drive, além de rotinas no Crontab.

Como Executar a Instalação

Com o servidor Ubuntu Server devidamente instalado e acessado como root (sudo -i), execute o comando abaixo para baixar o script direto do repositório e iniciar a automação completa:

Terminal Linux (Root) 
bash <(curl -s https://raw.githubusercontent.com/paulofbaldifh/Koha-/main/instalar.sh)
Nota importante: O script aguardará interativamente a conclusão do assistente web no navegador e prosseguirá automaticamente com a configuração do Elasticsearch logo em seguida.
